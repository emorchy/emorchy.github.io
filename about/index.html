About

Ethan Morchy is a CVE-reported hardware and software penetration tester experienced in performing vulnerability analysis and providing security recommendations for embedded medical, automotive, website/application, and code review (white/grey/black boxed). He has competed in numerous CTFs and specialized in binary exploitation and cryptography challenges. When he is not building an engineering project, he is probably creating software automation for routine tasks. His most useful skill is rapid skill acquisition for solving hard problems.

This website is a collection of talks, writeups, and projects that he has worked on.
